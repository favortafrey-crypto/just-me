# 🌌 My Universe

> A personal website exploring technology, creativity, engineering, and big ideas.

## 📖 About the Project

My Universe is a personal website created to bring together my interests, projects, ambitions, and experiences in one place.

It reflects my journey as a student and aspiring engineer who enjoys exploring technology, designing things, developing ideas, and discovering new possibilities.

The website combines a cosmic visual theme with interactive elements and personal storytelling to create an experience that feels more like exploring a world than browsing a conventional portfolio.

## ✨ Features

- **Home:** An introduction to me and my interests, featuring an illustrated avatar and cosmic-inspired visuals.
- **Maker's Lab:** An interactive timeline documenting my STEM journey, alongside a collection of projects and experiments.
- **Favéra:** A look into my crochet-inspired clothing brand, its beginnings, and my vision for its future.
- **Rebuilding Africa:** An introduction to my vision for community improvement, youth participation, and supporting vulnerable children.
- **Interactive Timeline:** JavaScript-powered chapters that let visitors explore different stages of my journey.
- **Custom Visual Design:** A consistent cosmic aesthetic featuring planets, stars, animations, and a dark colour palette.
- **Project Media:** Images and other media showcasing selected projects and experiences.

## 🛠️ Built With

- **HTML5** — Page structure and content.
- **CSS3** — Styling, layouts, animations, and responsive design.
- **JavaScript** — Interactive timeline and dynamic page elements.
